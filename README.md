# NPAK

## **Быстрый JavaScript-архиватор для формата `.npak`**, работающий как в Node.js, так и напрямую в браузере без отправки данных на сервер.

## [English](README.en.md) | [Русский](README.md)

## Ключевые особенности

- **Гибридный движок:** автоматически распознает несжимаемые файлы (медиа, бинарники) и упаковывает их напрямую без потери скорости.
- **Оптимизация для текста и кода:** использует статичные частотные словари и 4-битные коды для быстрой упаковки исходников и текстовых данных.
- **Надежная проверка целостности:** применяет криптографический хеш **SHA-256** вместо устаревшего CRC-32.
- **100% приватность в вебе:** веб-конвертер (`npak-web`) выполняет все операции локально в браузере пользователя — файлы не загружаются в сеть.
- **Двусторонняя конвертация:** поддерживает прямое и обратное преобразование `.zip ↔ .npak`.

## Сравнение: ZIP vs NPAK

| Критерий                   | ZIP                                               | NPAK                                                                                  |
| :------------------------- | :------------------------------------------------ | :------------------------------------------------------------------------------------ |
| **Технологии**             | C / C++                                           | JavaScript                                                                            |
| **Где работает**           | Встроен в большинство ОС                          | В браузере (`npak-web`) или через npm (`npak-archiver`)                               |
| **Сжатие текста и кода**   | Адаптивный алгоритм Deflate                       | Статичные частотные словари и 4-битные коды                                           |
| **Медиа и бинарные файлы** | Тратит ресурсы на попытки сжать уже сжатые данные | Гибридный движок распознает такие файлы и упаковывает их напрямую без потери скорости |
| **Проверка целостности**   | Базовый алгоритм CRC-32                           | Криптографический хеш SHA-256                                                         |
| **Приватность в вебе**     | Зависит от конкретного онлайн-сервиса             | Полная приватность: все операции идут локально в браузере, данные не уходят в сеть    |

## Использование

### В коде (ES Modules)

```javascript
import { packTargets } from "./pack.js";
import { unpackArchive } from "./unpack.js";

// 1. Упаковка файлов в формат .npak
const entries = [
  { path: "docs/", isDir: true, data: null },
  {
    path: "docs/hello.txt",
    isDir: false,
    data: new TextEncoder().encode("Привет, NPAK!"),
  },
];

const npakBytes = await packTargets(entries, (progress) => {
  console.log(`Прогресс упаковки: ${progress}%`);
});

// 2. Распаковка архива .npak
const extractedItems = await unpackArchive(npakBytes.buffer, (progress) => {
  console.log(`Прогресс распаковки: ${progress}%`);
});

console.log(extractedItems);
```

### Онлайн-конвертер (`npak-web`)

Вы можете запустить веб-интерфейс локально, открыв `index.html` через любой локальный сервер (например, `npx serve` или Live Server в VS Code):

```bash
npx serve .
```

> **Примечание:** Для работы ES-модулей (`pack.js` и `unpack.js`) в браузере страница должна открываться по протоколу `http://` или `https://`, а не напрямую через `file://`.
