NPAK — быстрый JavaScript-архиватор для формата .npak

Сравнение стандартного формата ZIP и современного веб-ориентированного архиватора NPAK.

Критерий ZIP NPAK
Технологии C / C++ JavaScript
Где работает Встроен в большинство ОС В браузере (npak-web) или через npm модуль (npak-archiver)
Сжатие текста и кода Адаптивный алгоритм Deflate Статичные частотные словари и 4-битные коды
Медиа и бинарные файлы Тратит ресурсы на попытки сжать уже сжатые данные Гибридный движок распознает такие файлы и упаковывает их напрямую без потери скорости
Проверка целостности Базовый алгоритм CRC-32 Криптографический хеш SHA-256
Приватность Зависит от конкретного онлайн-сервиса Полная приватность: все операции идут локально в браузере, данные не уходят в сеть
